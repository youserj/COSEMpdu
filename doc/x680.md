# X.680 — Tag Primitives

## Overview

The `x680` module contains the ASN.1 tag metadata (X.680) — universal tag numbers, tag classes, and the `Tag` structure — shared by the concrete codecs (`x690`, `acse`). It does not define abstract value types; the DLMS/COSEM PDUs are represented by their own concrete types (`acse`, `data`, `apdu`).

The module provides:
- **Universal tags** (`UniversalTag`) — the UNIVERSAL class tag-number table (X.680 Table 1).
- **Tag classes** (`Class`) and **tags** (`Tag`) — class + number + constructed flag.

Encoding/decoding is **not** performed here; that is the responsibility of the concrete codecs (`x690`, `ber`, `axdr`).

## Module Contents

### Universal Tags

| Variant | ASN.1 Type | Tag Number |
|---------|------------|------------|
| `UniversalTag::Boolean` | BOOLEAN | 1 |
| `UniversalTag::Integer` | INTEGER | 2 |
| `UniversalTag::BitString` | BIT STRING | 3 |
| `UniversalTag::OctetString` | OCTET STRING | 4 |
| `UniversalTag::Null` | NULL | 5 |
| `UniversalTag::ObjectIdentifier` | OBJECT IDENTIFIER | 6 |
| `UniversalTag::Real` | REAL | 9 |
| `UniversalTag::Enumerated` | ENUMERATED | 10 |
| `UniversalTag::Utf8String` | UTF8String | 12 |
| `UniversalTag::Sequence` | SEQUENCE | 16 |
| `UniversalTag::Set` | SET | 17 |
| `UniversalTag::UtcTime` | UTCTime | 23 |
| `UniversalTag::GeneralizedTime` | GeneralizedTime | 24 |
| `UniversalTag::VisibleString` | VisibleString | 26 |

Methods: `number()` (tag number as `u64`) and `from_number(n)` (look up by number).

### Tag Classes

| Variant | Raw bits |
|---------|----------|
| `Class::Universal` | `0x00` |
| `Class::Application` | `0x40` |
| `Class::Context` | `0x80` |
| `Class::Private` | `0xC0` |

Methods: `bits()`, `from_bits(bits)`.

### Tag

```rust
pub struct Tag {
    pub class: Class,
    pub number: u64,
    pub constructed: bool,
}
```

Constructors: `Tag::universal(tag)`, `Tag::context(number)`, `Tag::application(number)`.

## Usage

### Creating Tags

```rust
use cosempdu::x680::{Class, Tag, UniversalTag};

let universal_int = Tag::universal(UniversalTag::Integer);
assert_eq!(universal_int.number, 2);
assert_eq!(universal_int.class, Class::Universal);

let context_tag = Tag::context(0);
let app_tag = Tag::application(0);
```
