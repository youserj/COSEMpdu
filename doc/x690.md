# X.690 — BER/X.690 TLV Encoding

## Overview

The `x690` module implements basic BER (Basic Encoding Rules) TLV encoding according to the X.690 standard (ISO/IEC 8825-1). It provides low-level primitives for encoding/decoding tags, length, and content — the three components of a TLV structure.

The module is used as a foundation for:
- **BER codec** (`ber.rs`) — TLV encode/decode for all `Value` types
- **A-XDR codec** (`axdr.rs`) — uses the length primitives for variable-length aggregates
- **ACSE APDU** (`acse.rs`) — encoding ACSE messages in BER

## Module Contents

### `Length` Component

```rust
pub struct Length {
    pub value: i64, // >= 0 definite length; -1 indefinite form
}
```

| Method | Description |
|--------|-------------|
| `Length::new(value)` | Validate and construct a length |
| `encoded_len()` | Number of octets required to encode this length |
| `Length::get(buf)` | Decode a length from the buffer (advancing it) |
| `put(buf)` | Encode the length to the buffer (advancing it) |

### Tag Encoding/Decoding

| Function | Description |
|----------|-------------|
| `get_tag(buf)` | Decode a BER tag (advancing the buffer) |
| `put_tag(buf, tag)` | Encode a BER tag (advancing the buffer) |
| `validate_tag(buf, expected)` | Validate that the next tag matches `expected` (consuming it) |

### Length Helper

| Function | Description |
|----------|-------------|
| `put_length(buf, value)` | Write a raw length value (minimal octets, short/long form) |

## Usage

### TLV Encoding

```rust
use cosempdu::buffer::ByteBuffer;
use cosempdu::x680::{Class, Tag};
use cosempdu::x690::{put_length, put_tag};

let tag = Tag { class: Class::Application, number: 0, constructed: true };
let content = [0x01u8, 0x02, 0x03];

let mut backing = [0u8; 32];
let mut buf = ByteBuffer::new(&mut backing);
put_tag(&mut buf, &tag)?;
put_length(&mut buf, content.len() as i64)?;
buf.write(&content)?;
```

### TLV Decoding

```rust
use cosempdu::buffer::ByteBuffer;
use cosempdu::x690::{Tag, Length};

let mut backing = [0x60, 0x03, 0x01, 0x02, 0x03];
let mut buf = ByteBuffer::new(&mut backing);
let tag = Tag::get(&mut buf)?;
let length = Length::get(&mut buf)?;
let content = buf.read(length.value as usize)?;
println!("tag={tag:?} length={length} content={content:?}");
```

### Length Encoding

```rust
use cosempdu::buffer::ByteBuffer;
use cosempdu::x690::{put_length, Length};

let mut backing = [0u8; 8];
let mut buf = ByteBuffer::new(&mut backing);
put_length(&mut buf, 200)?;   // short form (1 byte)
put_length(&mut buf, 1000)?;  // long form (2+ bytes)

buf.set_pos(0)?;
assert_eq!(Length::get(&mut buf)?.value, 200);
assert_eq!(Length::get(&mut buf)?.value, 1000);
```
